Как начать

Четыре шага до первой игры

Первый запуск занимает 1–3 минуты, дальше лаунчер открывается мгновенно.

Скачайте

Установщик или portable-версию со страницы релизов.

Запустите

Если Windows покажет SmartScreen: «Подробнее» → «Выполнить в любом случае».

Подождите

Лаунчер скачает Java и последнюю версию игры.

Играйте

Когда статус станет «Установлена» — нажмите «Играть».

Готовы играть?

Данные игры хранятся локально, в папке %APPDATA%\.visuals-launcher.
